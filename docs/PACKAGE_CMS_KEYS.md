# Tour Package H1/H2 override keys

In Sanity -> Tour Packages -> H1 / H2 Overrides, add only the headings you actually want to change.

The current website heading remains the fallback when a key is absent.

## Common keys
- `hero` = main H1
- `intro` = first main H2 after hero
- `sacred-sites` = temples/destinations/sacred circuit section
- `package` = package/price/what is included style section
- `itinerary` = itinerary heading
- `inclusions` = inclusions/everything taken care of
- `why-margika` = why travellers choose Margika
- `booking` = how booking/yatra begins
- `testimonials` = traveller/yatri section
- `gallery` = gallery/moments section
- `related` = other packages/journeys
- `cta` = final booking CTA heading

## Heading fields
Each row has:
- Main Line 1
- Main Line 2 (optional)
- Accent / Italic Line (optional)

Example for Kerala H1:
- Section: `hero`
- Main Line 1: `Kerala Tour Packages`
- Main Line 2: `from Mumbai`
- Accent Line: `Munnar, Thekkady & Alleppey`

Use a single H1. Do not repeat the same target keyword mechanically in every H2.
